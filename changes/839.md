  definition names five Verified instances (every 100th id in lexicographic order), one budget

  baseline, US$1.6781 of the cap, and every failure; the README benchmark sentence now cites
  that measured pilot instead of the saturated C# suite (#624, #839).
- **A run's evidence is committed where its summary links it.** `first-run-2026-11-08` now ships
  one official evaluation result per instance and arm under `eval/swebench/runs/`, every instance
  row of the committed summary and of the write-up points at it instead of a machine-local
  temporary path, and the orchestrator's default work tree is the tracked `eval/swebench/runs`,
  so a clean checkout can follow a published resolved count to its official verdict (#624, #839).
