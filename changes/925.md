### Fixed

- **A CI job that never got a runner no longer files a bug card.** GitHub concludes a job it never
  acquired a hosted runner for as `cancelled` with an empty step list — "not acquired by Runner of type
  hosted even after multiple attempts" — and the red-run reporter filed a `kind/bug` card for such a
  leg that no change in this repository could close: one macOS capacity shortage filed two cards for a
  single push run, one of them for the perf leg that a push does not gate on. The reporter now files
  only for a job that ran and did not pass; a `cancelled` job that reached a step, and a job whose
  `steps` list is missing, still files, so the rule fails closed, and the run's own log names each
  unstarted job and says that a rerun is the remedy (#922).
