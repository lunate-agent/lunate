### Fixed

- **The verify gate's template roundtrip proves this checkout's contract, not a published one.**
  The contract roundtrip packs the four SDK packages at the version the release carries and builds
  the packaged-extension template against that feed, but a machine's global packages folder already
  holds a copy of the same id and version from the release, and NuGet binds an installed copy before
  it asks any source — so `verify (macos-latest, 1/2)` built the template against the published
  1.16.0 contract, not the tree's, and failed on the switch the hook-result unions close (CS8509).
  The roundtrip now restores into a packages folder of its own for the run, names the feed it just
  packed as a source, and builds from the assets file that restore wrote; a test pins the wiring and
  the restore behaviour it exists for (#932).
