### Changed

- **The contract's closed sets are closed in the compiler.** `AgentEvent` and `ExtensionEvent`, and
  the seven hook-result families (`ProjectTrustResult`, `InputReceivedResult`, `RunStartingResult`,
  `MessageCompletedResult`, `ToolCallingResult`, `TurnEndedResult`, `CompactingResult`), are C# 15
  `closed` records, so no assembly outside the contract can add an event kind or a result case and a
  consumer's `switch` is checked for exhaustiveness. **Version note for extension authors:** every
  type name, case name, constructor and the `IHookResult`/`IHookPayload` markers are unchanged, so
  `new ToolCallingResult.Block("held")` and `is ToolCallingResult.Block` compile as before — but an
  extension can no longer declare its own subclass of an event or a hook-result family, and adding a
  case to either set is a breaking contract change that moves the API version and gets its own note
  in [`docs/extensions/README.md`](../docs/extensions/README.md). The sets are not `union` types:
  a union's `Value` is `object`, which would erase the base that carries the stamped
  `SessionId`/`ParentRunId`/`Source` or the `IHookResult` marker, lose record equality, and cannot
  round-trip through `System.Text.Json` without a custom classifier
  ([ADR-0042](../adr/0042-contract-closed-sets.md)); the public API file does not move and the hook
  wire and `--json` shapes are unchanged (#919, #921).
