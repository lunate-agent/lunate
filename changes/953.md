### Fixed

- **A red test pass that named no test names its failing modules and the verdict it ended with.**
  `verify (macos-latest, 2/2)` of run 44466042157 failed its de-AT pass twice and the check run carried
  only `the test (de-AT culture) step failed (exit 1, 782s)`: the pass printed no failing-test line at
  all, which is what an aborted session, a crashed host or a module that never started looks like, and
  the annotation had nothing to name beyond the step. The gate reads that output anyway, so a pass
  without a test name now reports up to three of its failed modules — with the passed, failed and aborted
  counters the module line carries — and the run's own verdict line, without the exit-code link it ends
  with, in the same `::error::` annotations and job summary (#951).
