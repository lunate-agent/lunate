### Added

- **The release pull request's changelog edit is one command.** `scripts/changelog-assemble --release <version> [--date YYYY-MM-DD]` assembles the fragments, promotes `## [Unreleased]` to `## [<version>] - <date>` without the generated markers, leaves a fresh empty unreleased section, deletes the consumed fragments and bumps `<Version>`; it refuses, writing nothing, a version that is not newer, an existing release heading or an invalid fragment (#958).
