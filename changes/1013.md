### Added

- **A remote extension observes a turn, end to end.** Protocol version 3 projects the session's
  event stream to an out-of-process extension as `event/<kind>` notifications carrying the same JSON
  line `--json` writes; the `initialize` handshake negotiates the manifest's `events` watch list
  against the kinds the child accepts, and only the declared kinds it accepts are sent, never
  awaited. Each started child gets one bounded pump, so a slow child loses its oldest events —
  counted, warned once — instead of delaying the run, and an event over the wire's line cap is
  dropped rather than breaking the wire. A version-2 child still loads and is refused by name only
  when the manifest declares `events`; an observer-only remote extension now starts at session start.
  The `--json` projection moved into the wire package with `--json` delegating to it, so there is one
  event model, and the node reference extension speaks protocol 3, records what it observes and
  proves a real turn in its fitness test. Implements the wire half of
  [ADR-0040](../adr/0040-hook-based-extensibility-on-observables.md) (#1013).
