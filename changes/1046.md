### Added

- **A third Lunate arm on SWE-bench: the decision layer.** `eval/swebench/run.json` names a
  `decision` arm — a `main` chat model with a `decision` model advising it, `decisionLayer: "on"`
  and the note that explains it — so the configuration the numbers came from is committed data,
  not a command-line flag. The orchestrator turns that entry into the arm's `LUNATE_HOME`
  (`lunate-home/decision/settings.json` beside the run, copied into every instance run), whose
  `decisions` block runs routing and the approval gate in shadow — the two subjects its note
  declares, advice only — and forwards each model entry's credential variable by name, and starts
  no decision arm for mini-swe-agent, which has no decision layer. The run's one cap is US$2.00;
  reaching it stops the run and reports the spend and the limit stop (#859).

- **The SWE-bench summary measures all four numbers and cost per resolved instance.** Every
  instance row records resolved, spend, steps, `decisionSteps` and wall time in seconds, and every
  arm records `costPerResolvedUsd`; a decision model's call is a decision step, never an agent step,
  so the arms compare like for like. A decision arm's spend is the sum of the per-record prices the
  run stamped on its usage events — the main and decision models at their own rates — and one
  unpriced record makes the instance unpriced. `summary.md` shows wall time and cost per resolved
  instance beside the resolved count, spend and steps (#859).
