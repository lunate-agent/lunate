### Changed

- **The live area's input is a C# 15 union.** `LiveArea.LiveAreaInput` is a `private union` over
  the same cases instead of a private abstract record with thirty hand-written sealed subclasses,
  and the reducer is one exhaustive match, so a new case without a rule fails the build rather
  than falling through to an unchanged state. The painted frame, the public contract and the tests
  are unchanged (#903, #920).
