### Changed

- **Hand-built list and set arguments are collection expressions.** The output excerpt's whole,
  tail and elided line lists, the MCP tool list's unmatched-override set, the session history's
  replaced-id set and the extension tool registry's reserved names are built from one expression
  with `[with(...)]` instead of a capacity-plus-loop list or a `HashSet` constructor; the tree
  compiles at C# 15 on the pinned SDK 11, ahead of the `net11.0` target change (#905, #914).
