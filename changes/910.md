### Changed

- **Lunate runs on .NET 11.** The app, the tool and every internal project target `net11.0` with
  C# 15. **BREAKING** for `dotnet tool` users: the framework-dependent `lunate` package now carries
  a `net11.0` asset and requires the .NET 11 runtime. The self-contained installers are unchanged and
  still need no runtime (#192, #902).
- **The extension contract keeps its .NET 10 floor.** `Lunate.Contracts`,
  `Lunate.Extensibility.Abstractions`, `Lunate.Agent` and the `Lunate.Ai` assemblies it carries
  multi-target `net10.0;net11.0` with the same public surface, so an extension built against .NET 10
  keeps compiling and loading on the .NET 11 host. The test kit is `net11.0` because it references
  the tool graph (#902).
- **The startup budget was re-measured on .NET 11.** The floor stays below the local 150 ms budget
  (131–148 ms on the measurement machine). The idle-TUI memory subject could not run in the worker
  sandbox (no terminal can be allocated), so the memory gate remains a post-merge check on a machine
  that can (#902).
