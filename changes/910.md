### Changed

- **Lunate runs on .NET 11.** The app, the tool and every internal project target `net11.0` with
  C# 15. **BREAKING** for `dotnet tool` users: the framework-dependent `lunate` package now carries
  a `net11.0` asset and requires the .NET 11 runtime. The self-contained installers are unchanged and
  still need no runtime (#192, #902).
- **The extension contract keeps its .NET 10 floor.** `Lunate.Contracts`,
  `Lunate.Extensibility.Abstractions`, `Lunate.Agent` and the `Lunate.Ai` assemblies it carries
  multi-target `net10.0;net11.0` with the same public surface, so an extension built against .NET 10
  keeps compiling and loading on the .NET 11 host. The test kit is `net11.0` because it references
  the tool graph (#902).
- **The startup and idle-memory budgets were re-measured on .NET 11.** The startup floor stays below
  the local 150 ms budget (131–148 ms on the measurement machine). The idle TUI's own footprint is
  88 MB, inside the 150 MB memory gate and 3 MB above the .NET 10 baseline (85 MB); the published
  single-file ReadyToRun shape peaks at 353 MB against 298 MB on .NET 10, because the mapped
  ReadyToRun bundle grew 395 → 460 MB — the same host without ReadyToRun peaks at 85 MB, so the
  excess is bundle mapping, not the session. Whether ADR-0009 should gate that shape at a
  re-calibrated value is a budget decision after this change. The worker sandbox denies a terminal
  (`/dev/ptmx`) and `ps`, so the session was measured through the product's own console seam and
  libproc's RSS counter, with the ADR-0009 method (external peak-RSS sampler, 150 ms ticks, 20 s
  window). The welcome header's own budget now gates on the fastest of five first frames, the
  statistic `scripts/perf.sh` reads (ADR-0005 addendum): a cold test process JITs the whole
  interactive stack, so its one first frame measured the runner's tier-0 compilation rather than the
  header (260–275 ms cold against an 11–15 ms floor on the measurement machine, and 1.5–1.7 s on a
  CI runner whose verify step took four times its usual wall time) (#902).
