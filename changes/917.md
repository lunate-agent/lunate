### Changed

- **The tool, the app and every first-party project target `net11.0`, so C# 15 is one compiler
  version for the whole repository.** The pinned SDK `11.0.100` now matches the framework it builds;
  `Directory.Build.props` declares the target framework once and fixes `LangVersion` at `15.0`, which
  is what makes the two features that need the .NET 11 base class library — union types and closed
  hierarchies — available to first-party code (ADR-0041). No public API changes and no session-format
  change (#192, #917).
- **The extension contract keeps its `net10.0` promise.** `Lunate.Contracts`,
  `Lunate.Extensibility.Abstractions`, `Lunate.Agent` (with the `Lunate.Ai` and
  `Lunate.Ai.Decisions` assemblies it carries) and `Mermaid.Terminal` now publish a `net11.0` asset
  beside the `net10.0` one, with the same public API, so an extension built against the previous LTS
  keeps loading. The extension template builds both targets in the solution build — it clears the
  inherited `TargetFramework`, so MSBuild takes the cross-targeting path — and the floor is proven on
  every gate run (#192, #917).
- **The `dotnet tool` package needs the .NET 11 runtime.** `lunate` ships the `net11.0` tools asset
  only: `dotnet tool install -g lunate` therefore requires the .NET 11 runtime, while the
  self-contained release archives carry their own and are unchanged. Install an archive on a machine
  without the runtime (#192, #917).
- **Roslyn and NuGet move with the SDK, and the scripts stop spelling the framework folder.** The
  Roslyn packages go to `5.12.0` (the compiler SDK 11 ships) with `Microsoft.Build.Framework`
  `18.7.1`, `NuGet.*` to `8.0.0`; `scripts/lib.sh`'s `target_framework` and
  `Lunate.TestSupport.BuildOutput` derive the build output folder instead of hard-coding it, so the
  next target-framework move is one edit (#192, #917).
- **Startup is re-measured, not assumed, and the budget stands.** Against a `net10.0` binary built
  from `origin/main` with the same SDK on the same machine, the floor — the statistic the gate gates
  on — reads 119–149 ms before and 119–149 ms after (medians 169–170 ms and 200–208 ms), so the
  calibrated budgets keep their values (#192, #917).
