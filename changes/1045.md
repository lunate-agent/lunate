### Fixed

- **The SWE-bench adapter forwards the prepared home's credentials.** `scripts/eval/swebench.py`
  forwarded only the chat model's credential, so a `--lunate-home` that binds `usages.embeddings` could
  not resolve its own provider inside the container: the optional tool was not offered at all, and the
  "tool on" arm silently measured the "tool off" arm. Every `env:` reference the home names is
  forwarded too, and a reference to an unset variable stops the run instead of dropping the tool
  (#1045).

- **A committed run summary names its evidence by its place in the repository, never by the run
  host's path.** `workDir` was written as an absolute path whenever the run happened outside the
  repository — the usual case, since the harness needs Docker and a live credential — so a committed
  summary carried the maintainer's home directory. A row now names the committed run tree
  (`eval/swebench/runs/<run-id>/…`), which is exactly what the evidence check reads (#1045).
